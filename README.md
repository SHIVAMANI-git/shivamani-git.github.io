# Shivamani Boddupally Portfolio Website

This is a personal portfolio website for Shivamani Boddupally. It is hosted on GitHub Pages.

Live website:
https://shivamani-git.github.io

## About the Website

The website presents my profile, technical skills, education, projects, security write-ups, and includes a terminal simulation widget, contact form, and resume download link.

## Tech Stack

* HTML
* CSS
* JavaScript
* GitHub Pages
* Web3Forms
* hCaptcha

## Features

* Responsive design for desktop, tablet, and mobile
* Dark and light theme toggle
* Interactive terminal widget
* Skills filter by type
* Project filter by category
* Write-up modal reader for research publications
* Contact form integration with hCaptcha spam protection
* Direct resume download
* SEO optimization and social sharing metadata

## Local Setup

To run this project locally, clone the repository and navigate into the folder:

```bash
git clone https://github.com/SHIVAMANI-git/shivamani-git.github.io.git
cd shivamani-git.github.io
```

After cloning, open the `index.html` file in any web browser, or use the Live Server extension in Visual Studio Code.

## Deployment

The website is deployed using GitHub Pages directly from the main branch. Any updates pushed to the main branch will build and deploy automatically.
